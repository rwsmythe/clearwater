## Why

Run 6 proved the macOS build chain end to end with bundling OFF: the `.app` builds (506.4 MiB, 493 entries, 86 links), the hardened link rule and content check pass, the seal verifies, 136 bundle tests run green on the real bundle. What is still OFF is the FFmpeg bundle, because `notices.py:1435 _inventory` requires an onedir `_internal` folder and a `.app` has none; the Mac build therefore cannot write its notices, N13 cannot be met on the artifact, and `build.py` refuses `--notices` until the lock's census is complete. The real macOS FFmpeg lock (`ffmpeg-macos.lock.json`, tag `ffmpeg-9.0-gb204e94e-macos-arm64-nozvbi-9cb0fa8`, 36 component texts under `native-licences/ffmpeg-macos-components/`) has been on `wp6.5` since `02d07744`.
